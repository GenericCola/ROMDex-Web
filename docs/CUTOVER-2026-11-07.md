# Cutover to YouTrack storage, November 7, 2026

ROMDex metadata and NPCDex data moved from the private GitHub repository GenericCola/ROMDex-Data into two private YouTrack articles. The owner answered the two blocking questions first: nothing in NPCDex changed after October 22, so the ROMDex-Data snapshot is the source, and assigned status lives in the "ROMDex data" article. The desktop app was not running, and ROMDex-Data's head (bb3a751a, committed 2026-11-06 20:42 UTC) did not move during the run.

The run created both articles, uploaded every part, wrote manifest revision 1, then downloaded every part again and rebuilt each document to the hash above. A second run reported "already migrated" for both stores and wrote nothing.

The receipt, without signed download URLs, is in [evidence/cutover-receipt-2026-11-07.json](evidence/cutover-receipt-2026-11-07.json).

## Rollback

Nothing was deleted. ROMDex-Data, the desktop app, NPCD-660 and the 212 older `[NPCDex]` issues in NPCD are unchanged. To roll back, use the desktop app again and ignore the two articles.
